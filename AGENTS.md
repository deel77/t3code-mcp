# Repository workflow

Follow [CONTRIBUTING.md](CONTRIBUTING.md) when changing the bridge. For MCP tool changes, verify that the README Tools section and `docs/tools.md` match the registered tool names, inputs, defaults and response semantics before committing.

Run the relevant checks and inspect the staged diff for secrets and generated dependencies. Commit only the task's changes, push the current branch without force, and verify the remote commit before reporting completion.
